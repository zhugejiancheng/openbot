概览

OpenBot是一个功能强大的开源AI助手，能够执行各种任务，包括文件操作、系统命令执行、网络搜索等。通过自然语言与OpenBot交互，它可以理解和执行复杂的指令。

基本命令

通用命令

  • help 或 帮助 - 显示帮助信息
  • /help - 显示详细帮助信息
  • /tools - 显示可用工具列表
  • /health - 显示系统健康状态
  • /config - 显示系统配置

聊天相关

  • clear 或 清空对话 - 清空当前对话历史
  • history 或 历史 - 显示对话历史

可用工具

OpenBot集成了多种工具，可以通过自然语言指令调用：

文件操作工具

  • read - 读取文件内容
  • write - 写入内容到文件
  • edit - 编辑文件内容
  • exec - 执行系统命令
  • process - 管理后台进程

网络工具

  • web_search - 搜索网络
  • web_fetch - 抓取网页内容
  • browser - 控制浏览器
  • image - 分析图像

数据管理工具

  • feishu_doc - 飞书文档操作
  • feishu_wiki - 飞书知识库操作
  • feishu_drive - 飞书云文档操作
  • feishu_bitable - 飞书多维表格操作

系统管理工具

  • cron - 定时任务管理
  • message - 消息发送
  • memory_search - 搜索记忆
  • memory_get - 获取记忆片段

API接口

OpenBot提供丰富的API接口，可用于程序化访问：

基本接口

  • GET / - 获取基本信息
  • GET /health - 健康检查
  • POST /chat - 英文聊天接口
  • POST /chinese-chat - 中文聊天接口
  • GET /tools - 获取可用工具列表

文件操作接口

  • GET /files/list - 列出文件
  • GET /files/read - 读取文件
  • POST /files/write - 写入文件
  • POST /files/delete - 删除文件

系统监控接口

  • GET /monitor/system-info - 系统信息
  • GET /monitor/cpu-usage - CPU使用情况
  • GET /monitor/memory-usage - 内存使用情况

故障排除

常见问题

  • 无法执行命令: 检查命令语法是否正确，或是否具有相应权限
  • 文件操作失败: 确认文件路径是否存在，或是否有足够权限
  • 网络搜索无结果: 检查网络连接，或尝试更具体的搜索词
  • 工具不可用: 检查系统配置，确保所需依赖已安装
